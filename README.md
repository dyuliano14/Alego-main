# 📚 Controle de Estudos - ALEGO

Bem-vindo ao **Controle de Estudos ALEGO**!  
Este é um projeto pessoal e educacional voltado para organização e revisão de conteúdos, com foco em concursos públicos, especialmente voltado à preparação para a **Assembleia Legislativa de Goiás (ALEGO)**.

> _"Aprender é ensinar!"_  
> Este projeto combina Markdown, HTML, CSS e conceitos de produtividade para maximizar o aprendizado. 💡
